# Nexus Downloads

Aktuelle Version: **0.4.14**.

[Nexus-setup.exe herunterladen](https://github.com/ovaNite/Nexus-Desktop/releases/latest/download/Nexus-setup.exe)

Vollständiger Offline-Installer mit Desktop-Verknüpfung, Start-Updater, dauerhaft gespeicherten Themes/Skripten und überarbeiteter Oberfläche. Erstinstallationen verwenden vorzugsweise D:\Nexus, der Installationsordner bleibt wählbar. Nexus und Roblox vor dem Installieren normal schließen.

Dieses öffentliche Repository enthält nur die Download-Dokumentation. Quellcode und Entwicklungshistorie liegen separat privat. Es werden keine Quellcode-ZIPs hochgeladen.

Die aktuellen [Release-Hinweise und Prüfberichte](https://github.com/ovaNite/Nexus-Desktop/releases/latest) erläutern die tatsächlichen Tests und Grenzen. Native Roblox-Abstürze sind noch nicht nachweislich behoben; die neue Ausgabe ergänzt Diagnose und Auto-Attach-Pause bei zugeordneten Abstürzen. Kein neuer offizieller sUNC-Wert, keine Antivirus-Freigabe.
