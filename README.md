# Nexus Downloads

Aktuelle Version: **0.4.13**.

[Nexus-setup.exe herunterladen](https://github.com/ovaNite/Nexus-Desktop/releases/latest/download/Nexus-setup.exe)

Der Offline-Installer enthält die Oberfläche und alle benötigten Laufzeitdateien. Nexus und Roblox vor dem Installieren normal schließen und danach frisch starten. Der Installationsordner ist wählbar, für eine Erstinstallation wird D:\Nexus bevorzugt.

Dieses Repository enthält keine proprietären Entwicklungsquellen und keine Quellcode-ZIPs. Quellcode und Entwicklungshistorie werden separat privat gepflegt. Die von GitHub automatisch erzeugten Repository-Archive enthalten hier nur diese Download-Dokumentation.

Unterstützung für eigene Lua-Tabellen, eigene Metatables und Nexus-eigene Hook-Closures ist begrenzt und wird in den Release-Hinweisen erläutert. Ein offizieller sUNC-Wert von 60, beliebige native Hooks oder Antivirus-Unbedenklichkeit werden nicht behauptet. Bitte die jeweiligen [Release-Hinweise](https://github.com/ovaNite/Nexus-Desktop/releases/latest) und den Prüfbericht beachten.
